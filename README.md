# E-commerce Customer Behavior Analysis (Python / Pandas)


**Goal:** Analyze a public online retail transactional dataset to extract business insights: top products, seasonality, revenue drivers, customer segmentation (RFM), cohort/retention analysis and actionable recommendations.


## Dataset
The public **Online Retail** dataset (UCI / Online Retail II) is used. The dataset contains UK non-store online retail transactions (2009–2011) and includes invoices, product descriptions, quantities, prices and country codes.


## Project tasks / pipeline
1. Data loading & cleaning (remove cancellations, negative quantities, NaNs, convert dates)
2. Exploratory Data Analysis (sales over time, top countries, top products, price distributions)
3. Revenue and customer-level metrics (LTV exploratory)
4. RFM segmentation (Recency, Frequency, Monetary)
5. Cohort and retention analysis (monthly cohorts, retention matrix)
6. Business insights & recommendations (marketing & product suggestions)
